## 5. 第一性原理回看

这个产品的目标不是“让更多端点返回 200”，而是降低一位创作者从意图到可信作品的总认知负担，同时保留人的判断权。因此可用性必须同时满足：

1. 输入是真实意图和可追溯来源，而不是生成器自己补齐的假上下文；
2. AI 只提出候选，人的选择、编辑、版本和否决必须可见、可恢复；
3. 主稿、视觉和平台稿之间有清楚的依赖关系，但任何上游变化都不能静默覆盖下游；
4. “完成”必须指向可检查的作品包，不是测试数、卡片数或生成篇数；
5. 发布是不可逆外部副作用，必须和内容生成彻底分开，并由真实作者最后确认。

此前工作最大的偏差，是把“R1—R9 功能存在且测试全绿”误当作“产品可用”。真实路径证明，价值断点恰好藏在自动化测试原先没覆盖的连接处：真实起稿、图像 provider 缺失时的恢复、引用渲染、审批归属、晚改主稿后的下游恢复和最终安全交付。
