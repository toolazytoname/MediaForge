# 2026-08-14 通宵：图文优先，平台适配，视频后置

用户离开前确认：先把图文做好；同一主题按平台生成不同内容；流程分受控和全自动；视频以后再做。本文把已确认产品定义和当晚实现钉在一起。真发、小红书真发、无人值守发布仍禁止。

## 1. 今晚做成的产品形状

打开 `/`：

- **生成文章**（受控）：主题 + 想法 → 一篇带图的主稿 → 人改一段或整篇 → 需要时再点「生成微信和头条稿」。
- **全自动准备双平台稿**：同一输入继续生成微信、头条两份独立稿，然后停在微信阅读预览。

两份平台稿互不覆盖，也不覆盖主稿。完成态是看见文章和平台预览，以及 Markdown 导出。ZIP 只是备份。`publish.enabled` 保持 false。

主导航变成：文章 / 微信 / 头条 / 更多。资料、配图、审批退到「更多」。

## 2. 平台怎么不一样

| 平台 | 今晚怎么处理 | 明确不做 |
| --- | --- | --- |
| 微信公众号 | 长文、摘要、封面和插图、阅读预览、Markdown 导出 | 不调用 draft/add，不群发 |
| 今日头条 | 更直接的标题和开头、更高信息密度、独立正文 | 不走 Playwright 真发 |
| 小红书 | 「更多」里只给照片+短文案形态预告 | 不写 variants、不渲卡片矩阵、不调 CLI |
| 视频 | 规格见下节 | 不把六步引擎向导做成主路径 |

实现：`POST /api/v1/projects/{id}/prepare-platforms` 一次准备微信和头条。AI 适配失败则复制主稿，保证自动路径仍有可编辑草稿。

## 3. 视频：为什么后置，下一步最小做什么

仓库里已有 MPT 混剪、Pixelle 分镜、LatentSync 数字人桥，以及 `/creation/video` 六步向导。它们是引擎配置，不是创作者工作区。

图文黄金路径没站住以前，视频会再次变成「能力能拼、人不会用」。图文验收过了之后，最小下一步是：

1. 从已确认主稿派生 60–90 秒口播和镜头卡（文本即可）。
2. 工作区加「视频脚本」，不要把引擎向导当入口。
3. 只有本机引擎活着才允许一次低清试渲。数字人、视频号、B 站发布都不做。

## 4. 受控和全自动

不是四个自主程度滑杆。是两个入口，共用主稿、图片、平台稿和安全门。

- 受控：人一直看得见文章，平台稿要再点一次。
- 全自动：机器把双平台草稿也准备好，等人审。禁止跳过确认去真发。

## 5. 第二天醒来可以怎么验收

1. 打开 http://127.0.0.1:5173/
2. 受控：生成文章，点一段改，采用或不采用。
3. 点「生成微信和头条稿」，分别打开微信/头条页看预览。
4. 或用「全自动准备双平台稿」一次走到微信预览。
5. 导出 Markdown。不要开发布总闸。
